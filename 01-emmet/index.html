01-Emmet

Puglin for faster HTML and CSS coding.

01-Child: >
Creates child elements (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: +
Creates Sibling elements.

Example:

section+header+nav ↔️

Result:

<section></section> <header></header> <nav></nav>

03-multiplication: *
Repeats elements multiple times.

Example:

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class: .
Creates a class attribute.

Example:

menu.mainmenu ↔️

.container ↔️

Result:

<menu class="mainmenu"></menu> <div class="container"></div>

05-Classes: ...
Creates multiple class attributes.

Example:

menu.main.uppercase.blue ↔️

Result:

<menu class="mainmenu uppercase blue"></menu>

06-ID: #
Creates an ID attribute.

Example:

nav#menu ↔️

Result:

<nav id="menu"></nav>

07-Text: {}
Inserts text content.

Example:

div{Lorem Ipsum Dolor} ↔️

a{Click Aquí} ↔️

Result:

<div>Lorem Ipsum Dolor</div> <a href=“”>Click Aquí</a>

08-Custom Attribute: []
Creates custom attributes.

Example:

a[href=www.google.com] ↔️

Result:

<a href="www.google.com"></a>

09-Item Numbering: $
Adds consecutive numbers.

Example:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering.: @-
Adds consecutive numbers.

Example:

ul>li.num$@-*3 ↔️

Result:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Numbering: @n
Defines a base number for sequences.

Example:

ul>li.num$@3*4 ↔️

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class=“num5"></li> <li class=“num6"></li> </ul>

12-Climb Up: ^
Moves up one level.

Example:

section>article>div^p ↔️

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping: ()
Groups elements together.

Example:

(header>nav)(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem: Lorem
Generates placeholder text.

Example:

lorem5 ↔️

Result:

lorem5

15-HTML Documents: html
Generates placeholder text.

Example:

html:5 ↔️

Result:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

16-Meta Tags: Meta
Generates meta tags.

Example:

meta:vp ↔️

Result:

<meta name="viewport">
